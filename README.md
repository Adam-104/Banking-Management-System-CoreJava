# 🏦 Banking Management System (Core Java)

A console-based Banking Management System built with **Core Java**, following **Object-Oriented Programming (OOP)** principles and a clean, layered architecture (service / repository / model).

The project simulates a real banking application with **customer** and **admin** roles, PIN-based authentication with account locking, money transfers, transaction history, and data persistence to disk via Java serialization.

---

## 📌 Features

### 👤 Customer

- Create a Savings or Current account
- PIN-based login (account locks after 3 failed attempts)
- Check account balance
- Deposit / withdraw money
- Transfer money to another account
- View full transaction history
- View a mini statement (last 5 transactions)
- Change PIN
- SMS / Email notifications (simulated)

### 🛡️ Admin

- Secure admin login
- View all accounts
- Search account by account number or customer name
- Delete an account
- Unlock a locked customer account
- View total customers and total bank balance
- Sort accounts (by number, name, balance, or type)
- View bank-wide statistics (totals, averages, highest/lowest balance)
- Export a full customer report to `customer_report.txt`

### 💾 Persistence

- All accounts are saved to `accounts.dat` (Java object serialization) and reloaded automatically the next time the app starts, so data survives between runs.

### ⚠️ Robust error handling

- Custom exception hierarchy for invalid input, locked accounts, insufficient balance, and more, so the app never crashes on bad input — it reports a clear error and keeps running.

## 🚀 Getting Started

### Prerequisites

- JDK 25
- IntelliJ IDEA (recommended) or any Java IDE / the `javac`/`java` command-line tools
- Git

### Run from IntelliJ IDEA

1. Open the project folder in IntelliJ IDEA.
2. Let it index the project (it's already set up as an IntelliJ module).
3. Run `src/app/Main.java`.

### Run from the command line

```bash
# From the project root
cd src
javac -d ../out app/*.java model/*.java service/*.java repository/*.java notification/*.java exception/*.java util/*.java
java -cp ../out app.Main
```

## 📚 Object-Oriented & Java Concepts Demonstrated

- Classes, objects, encapsulation, inheritance, polymorphism, abstraction
- Interfaces (e.g. `NotificationService`)
- Abstract classes and method overriding (`Account.accountFeatures()`)
- Custom checked/unchecked exception hierarchy and exception propagation
- Repository pattern for data access
- Constructor-based dependency injection
- Collections (`ArrayList`) and `Comparator`-based sorting
- File I/O: `BufferedWriter` for report export, `ObjectInputStream`/`ObjectOutputStream` for persistence
- Java serialization (`Serializable`)

## ⚠️ Exception Handling

A dedicated exception hierarchy keeps error handling clean and predictable:

- `BankException` — base exception for all banking errors
- `InvalidAmountException`
- `InvalidPinException`
- `AccountNotFoundException`
- `AccountAlreadyExistsException`
- `InsufficientBalanceException`
- `SameAccountTransferException`
